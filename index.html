Agentic RAG Research Assistant

Python · ReAct Agent Pattern · Tool-Calling · Self-Correcting Retrieval

A framework-free agent built around the ReAct (Reason → Act → Observe) loop. It routes each query to the right tool, and — the part that makes it "agentic RAG" rather than plain RAG — reformulates and retries retrieval on its own when confidence in the result comes back low, instead of silently handing weak context to generation.

Route
Classifies each query to the right tool: retriever, calculator, or web search
Act
Calls the selected tool and captures a confidence score with the result
Reflect
Below-threshold retrieval triggers automatic query reformulation and a retry
Synthesize
Produces a final answer grounded in whichever observation cleared the bar
3 pluggable tools, one shared interface — drop in a real vector DB or LLM call with a two-line swap
